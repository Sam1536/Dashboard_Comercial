
# 🛒 Dashboard Comercial | Power BI

Dashboard interativo de vendas que acompanha **faturamento**, **total de vendas**, **ticket médio** e **quantidade de clientes**, com evolução ao longo do tempo, desempenho por marca e uma página de **árvore de decomposição** para explorar o faturamento em detalhe.

🔗 **[Alguns Dashboard no meu Portfólio ](https://sites.google.com/view/portifoliosamuelmarianomelo/in%C3%ADcio)**

## ✨ Recursos

- Indicadores de **Faturamento Total**, **Total de Vendas**, **Ticket Médio** e **Quantidade de Clientes**
- Evolução de cada indicador por data da venda
- Faturamento por marca
- Grade com as imagens dos produtos
- Árvore de decomposição por categoria, marca e produto

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query · Visuais personalizados (gráficos de evolução e grade de imagens)

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**. Alguns visuais são personalizados e, se necessário, serão carregados do próprio arquivo.
